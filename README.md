# 炸金花（Golden Flower Poker）

基于 Qt6 / C++17 的炸金花游戏，支持本地人机对局，以及同一局域网内的桌面端、手机浏览器混合联机。

## 功能

- 蒙牌、看牌、跟注、加注、比牌、弃牌。
- 四种 AI 策略：谨慎型、激进型、简单型、自适应型。
- 默认 1 位房主和 3 位 AI；牌桌总人数可选 2–17 人，空位由 AI 补足。
- 手机通过房间二维码或地址加入，桌面端通过房主 IP 加入。
- 房主统一维护 15 秒操作倒计时，超时自动弃牌。
- 掉线后由 AI 接管原座位，保留本局手牌、筹码和看牌状态。
- 桌面可滚动玩家网格、手机响应式布局、下注金额提示和结算展示。
- 多局筹码存档、资金流水、战绩与最近对局记录。
- 房主可通过“重开牌桌”选择每位玩家的起始筹码，恢复筹码不足的牌桌。

## 构建与运行

依赖 CMake 3.16+、C++17 编译器，以及 Qt6 的 Core、Gui、Widgets、Network、WebSockets 模块。构建测试还需要 Qt6 Test；libqrencode 可选，未安装时显示可复制的房间地址。

```bash
cmake -S . -B build-review -G Ninja
cmake --build build-review
./build-review/PokerGame
```

Qt 安装在自定义目录时，可给 CMake 传入 `-DCMAKE_PREFIX_PATH=/path/to/Qt`。仅构建游戏可加 `-DBUILD_TESTING=OFF`；未安装 Ninja 时可以省略 `-G Ninja`。

`build-review/` 用作独立构建目录，避免改动仓库历史上仍被跟踪的部分 `build/` 缓存。

在 VS Code 中打开项目文件夹后，可在“运行和调试”中选择“启动 PokerGame (调试)”并按 F5；启动前会自动运行 CMake 配置与构建。默认构建任务也已设为 CMake，使用整个 Qt 项目构建。

## 重开与起始筹码

1. 房主点击底部“重开牌桌”。本地人机游戏也使用此入口。
2. 输入每位玩家的起始筹码，范围为 **20–1,000,000**，初次默认 1000，之后记住上次设置。
3. 点击“确认重开”。所有座位统一重置筹码，清空当前奖池、手牌和倒计时，保留已连接玩家及历史战绩。
4. 点击“开始游戏”重新发牌。底注从新设置的筹码中正常扣除。

重开可在对局中使用，被中止的牌局不计胜负。选择“取消”不会重开；弹窗打开期间当前牌局及倒计时仍会继续。“再来一局”则沿用剩余筹码，不做补充。重开后的筹码和起始设置会保存；桌面客户端和手机会同步收到重开状态，无需重新连接。

## 局域网联机

1. 房主打开游戏，点击“创建房间”。
2. 所有设备连接同一 WiFi / 局域网。
3. 手机浏览器扫码，或打开弹窗中的 `http://房主IP:8080`；桌面客户端点击“加入房间”，输入 `房主IP:12345`。
4. 玩家在两局之间入座，优先接替 AI 座位并继承该座位筹码。所有设备入座后，由房主开始游戏。
5. 游戏中打开页面或掉线重连，会等待本局结束再申请座位。当前实现不保证重连回到原座位。

手机通信使用 WebSocket 端口 **12347**，网页使用 HTTP 端口 **8080**，桌面通信使用 TCP 端口 **12345**。房主系统防火墙需允许同一局域网访问这些端口。重复点击“房间二维码”可再次查看地址。

## 当前游戏规则

牌型顺序为：豹子 > 顺金 > 金花 > 顺子 > 对子 > 单张。A-2-3 是最小顺子。三种不同花色的 2、3、5 可以打败豹子，但输给其他普通牌型；两个特殊 235 比较 5 的花色。相同点数按原项目的花色规则比较：黑桃 > 红桃 > 梅花 > 方块。

| 操作 | 费用与行为 |
|------|------------|
| 底注 | 每局开始每位参局玩家投入 10 筹码 |
| 看牌 | 免费，不结束当前回合，也不重置倒计时；之后跟注金额翻倍 |
| 跟注 | 蒙牌支付当前暗注，看牌支付当前暗注的两倍 |
| 加注 | 可选跟注、2 倍、3 倍、最大可下注；桌面端另有自定义金额 |
| 比牌 | 发起者支付自身跟注金额的两倍，落败者退出本局 |
| 弃牌 | 不额外扣筹码，退出本局 |

下注不能超过剩余筹码，也不能低于当前跟注要求；看牌后的下注金额必须为偶数。“最大可下注”会据此调整金额。沿用原项目的单奖池规则，不提供边池：后续回合无法支付跟注时自动弃牌。底注不足者暂不参局，至少两位玩家能支付底注才可开局。

未看牌时，服务器不会向客户端发送该玩家的牌值；对局结束后再同步各参局玩家的手牌。

## 测试

```bash
ctest --test-dir build-review --output-on-failure
```

测试使用临时存档目录，不覆盖日常游戏存档。联机测试需要能创建本机网络套接字，并使用空闲的 8080、12345、12347 端口。安装 Node.js 后还会运行手机端交互测试，也可单独执行：

```bash
node --test tests/web-client.test.js
```

## 项目结构

```text
src/
├── ai/            # AI 策略
├── controller/    # 对局、倒计时、联网与界面协调
├── core/          # 牌型、玩家、牌局引擎
├── network/       # HTTP、WebSocket、TCP
├── ui/            # Qt 桌面界面
└── utils/         # 日志、筹码存档与战绩
web/               # 随 Qt 资源打包的手机端 HTML / CSS / JavaScript
tests/             # Qt 回归测试与手机端交互测试
```
